# Explorador de Catálogo de Arte

## Integrantes del grupo
- Jesus Oliveros
- Cristian Varela

## Descripción
App desarrollamos con React que permite explorar obras de arte del Metropolitan Museum of Art, consultar sus detalles, guardar obras favoritas y CRUD con usuarios registrados.

## Tecnologías utilizadas
- React
- JavaScript
- Vite
- React Router DOM
- CSS
- LocalStorage

## API utilizada
**Metropolitan Museum of Art Collection API**

La API permite consultar obras de arte y obtener información como el título, artista, fecha y departamento.

## Funcionalidades
- Listado de obras de arte.
- Búsqueda de obras.
- Filtro por departamento.
- Carga de más resultados.
- Vista detallada de cada obra.
- Gestión de favoritos con persistencia en LocalStorage.
- Registro, edición y eliminación de usuarios.
- Navegación entre páginas.
- Diseño adaptable a diferentes tamaños de pantalla.

## Instalación y ejecución

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Ejecutar en la terminal:

   `npm install`

4. Iniciar el proyecto:

   `npm run dev`

5. Abrir en el navegador la dirección que muestra la terminal.
